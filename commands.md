# Commands

All commands below assume you are in the repository root:

```bash
cd /.../GpuComp2026SS_02
```

## Build Folder

The `build/` directory is generated by CMake and should not be pushed to git. It is already listed in `.gitignore`.

If `build/` was already tracked by git, stop tracking it while keeping the local folder:

```bash
git rm -r --cached build
git add .gitignore
```

## Configure And Build

Default debug build. This prints pipeline debug logs, puzzle piece results, and sub-stage timings:

```bash
cmake -S . -B build
cmake --build build --target pipeline -j
```

Build without debug output:

```bash
cmake -S . -B build -DPIPELINE_DEBUG_OUTPUT=OFF
cmake --build build --target pipeline -j
```

Build with debug output but without sub-stage timings:

```bash
cmake -S . -B build -DPIPELINE_DEBUG_OUTPUT=ON -DPIPELINE_SUB_TIMINGS=OFF
cmake --build build --target pipeline -j
```

Build with debug output and sub-stage timings explicitly enabled:

```bash
cmake -S . -B build -DPIPELINE_DEBUG_OUTPUT=ON -DPIPELINE_SUB_TIMINGS=ON
cmake --build build --target pipeline -j
```

Clean rebuild from scratch:

```bash
rm -rf build
cmake -S . -B build
cmake --build build --target pipeline -j
```

Parallel build using all available CPU cores:

```bash
cmake --build build --target pipeline -j "$(nproc)"
```

## Run Pipeline

Run with the default image from `PipelineOptions`:

```bash
./build/pipeline
```

Run with a specific input image:

```bash
./build/pipeline data/single.JPG
```

Run with a specific input image and output directory argument:

```bash
./build/pipeline data/single.JPG data/pipeline_output
```

Run another dataset image:

```bash
./build/pipeline data/1_p1.jpg data/pipeline_output
```

## Expected Debug Output

When `PIPELINE_DEBUG_OUTPUT=ON`, the executable prints:

- Pipeline step logs, for example preprocessing, cleaning, contour extraction.
- Number of detected puzzle pieces.
- For each puzzle piece: edge labels, corner indices, contour sizes, circle center, circle radius.
- Total runtime.
- Sub-stage timings when `PIPELINE_SUB_TIMINGS=ON`.

When `PIPELINE_DEBUG_OUTPUT=OFF`, `print_summary()` and debug logging are not compiled into the executable.

## Useful CMake Targets

Build only the pipeline executable:

```bash
cmake --build build --target pipeline -j
```

Build the serial module library:

```bash
cmake --build build --target serial_pipeline_modules -j
```

Build the reusable pipeline library:

```bash
cmake --build build --target pipeline_core -j
```

## Verify Debug Code Is Disabled

Configure and build a non-debug executable in a temporary build folder:

```bash
cmake -S . -B /tmp/gpucomp-nodebug -DPIPELINE_DEBUG_OUTPUT=OFF
cmake --build /tmp/gpucomp-nodebug --target pipeline -j
```

Check that debug symbols are absent:

```bash
nm -C /tmp/gpucomp-nodebug/pipeline | rg "print_summary|debug_print"
```

No output means the debug functions are not present.

## CUDA Pipeline

### Configure And Build

CUDA must be enabled explicitly via `-DPIPELINE_ENABLE_CUDA=ON`.

Default debug build:

```bash
cmake -S . -B build -DPIPELINE_ENABLE_CUDA=ON
cmake --build build --target pipeline_cuda -j
```

Build without debug output:

```bash
cmake -S . -B build -DPIPELINE_ENABLE_CUDA=ON -DPIPELINE_DEBUG_OUTPUT=OFF
cmake --build build --target pipeline_cuda -j
```

Clean rebuild from scratch:

```bash
rm -rf build
cmake -S . -B build -DPIPELINE_ENABLE_CUDA=ON
cmake --build build --target pipeline_cuda -j
```

### Run CUDA Pipeline

Run with the default image:

```bash
./build/pipeline_cuda
```

Run with a specific input image:

```bash
./build/pipeline_cuda data/single.JPG
```

Run with a specific input image and output directory:

```bash
./build/pipeline_cuda data/single.JPG data/pipeline_output
```

Run another dataset image:

```bash
./build/pipeline_cuda data/1_p1.jpg data/pipeline_output
```

## Git Status

Show all changed files:

```bash
git status --short
```

Show changed source files while ignoring generated build output:

```bash
git status --short -- ':!build'
```

Show the diff for the pipeline and CMake files:

```bash
git diff -- CMakeLists.txt include/serial/pipeline.hpp src/serial/pipeline.cpp
```

## Commit Typical Changes

After checking the diff:

```bash
git add CMakeLists.txt include/serial/pipeline.hpp src/serial/pipeline.cpp include/types.hpp include/serial/signal_analysis.hpp commands.md .gitignore
git commit -m "Update serial pipeline build and debug output"
```
